# 環境レポート

スモークテスト：コンテナでコマンドを実行できることを確認し、その結果を報告します。
低コストで実施してください。ツール呼び出しは1回、短いレポート1つだけとします。

## 手順

1. コレクタースクリプトを**正確に1回だけ**実行してください。他のコマンドは実行しないでください。

   ```
   bash /app/bin/collect-env.sh
   ```

2. 以下のレポートを最終メッセージとして出力してください。スクリプトを再実行したり、ファイルを読み取ったり、追加の調査を行ったりしないでください。

## レポート形式

最終メッセージは、以下のMarkdownと**完全に同じ形式で、それ以外は何も書かないでください**。前置きや締めの文章も不要です。

```markdown
# エージェント・コンテナ・ヘルスチェック

| Check | Value |
|-------|-------|
| OS / アーキテクチャ | ... |
| Python | ... |
| git | ... |
| 作業ディレクトリ | ... |
| 書き込み可能な出力ディレクトリ | ... |

**判定:** すべてのチェックで値が返された場合は `healthy`、失敗したチェックがある場合は `degraded` とし、失敗したチェック名を記載した1文。
```

値はスクリプトの出力からそのままコピーしてください。エラーが報告された行については、そのエラー内容を省略せず、表に記載してください。
